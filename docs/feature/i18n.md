| `Language` | Bundle file | `Accept-Language` |
|------------|-------------|-------------------|

| TH | `messages_th.properties` | `th` |

| TL | `messages_tl.properties` | `tl` |
| KO | `messages_ko.properties` | `ko` |
| JA | `messages_ja.properties` | `ja` |
| ZH | `messages_zh.properties` | `zh` |
| HI | `messages_hi.properties` | `hi` |

| DE | `messages_de.properties` | `de` |
| ES | `messages_es.properties` | `es` |
| IT | `messages_it.properties` | `it` |
| RU | `messages_ru.properties` | `ru` |
| NL | `messages_nl.properties` | `nl` |
| PL | `messages_pl.properties` | `pl` |
| PT | `messages_pt.properties` | `pt` |
| AR | `messages_ar.properties` | `ar` |
| TR | `messages_tr.properties` | `tr` |

Add the same keys to every file when introducing new `error.*` or `valid.*` messages.
